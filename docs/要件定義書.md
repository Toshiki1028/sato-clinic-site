# 佐藤医院 Webサイト 要件定義書

## 1. プロジェクト概要
佐藤医院の公式Webサイトをリニューアルする。

現行サイトは古く、スマートフォンやタブレットでの閲覧に対応していないため、
患者が必要な情報へたどり着きやすく、安心感・信頼感のあるWebサイトを制作する。

## 2. 目的
- 必要な情報へ素早くたどり着けるナビゲーションを実現する
- 清潔感・親しみやすさのあるデザインにする
- スマートフォン・タブレットに対応する
- 高齢者にも読みやすい文字サイズ・レイアウトにする

## 3. ターゲット
主な利用者は以下とする。

- 中高年
- ファミリー層
- 高齢者
- 学生・若年層
- 幼児・小児
- その他の来院者

## 4. トップページ構成
トップページは以下の順序を基本とする。

1. ファーストビュー
2. 診療時間
3. お知らせ
4. 院長挨拶
5. 診療内容
6. 当院について
7. スタッフ紹介
8. アクセス
9. フッター

アクセスはフッター直前に配置する。

## 5. デザイン要件

### トーン
- 清潔感
- 親しみやすさ
- 地域に根ざした医療の印象

### 配色
- 白を基調とする
- 薄いグリーンをサイトのテーマカラーとして使用する

### 写真
支給された画像を使用する。

### 可読性
高齢者にも読みやすい文字サイズ・行間を意識する。

### キャッチコピー
「地域に根ざした医療」を目立たせる。

### NG
必要以上に派手なデザインは避ける。

## 6. 機能要件
- レスポンシブ対応
- お知らせ表示
- Googleマップまたはアクセス情報の表示
- ナビゲーション
- スマートフォン用メニュー
- 各セクションへのリンク

## 7. 掲載情報

### 診療時間
- 午前：9:00〜12:00
- 午後：13:00〜18:00
- 休診日：木曜・土曜午後・日曜

### 受付時間
- 午前：8:00〜11:00
- 午後：12:00〜17:00

### 診療科目
- 内科
- 循環器科
- 呼吸器科
- 予防医療・健康診断
- 生活習慣病の治療・管理
