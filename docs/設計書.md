# 佐藤医院 Webサイト 設計書

## 1. サイト構成

トップページは以下のセクションで構成する。

1. ヘッダー
2. ファーストビュー
3. 診療時間
4. お知らせ
5. 院長挨拶
6. 診療内容
7. 当院について
8. スタッフ紹介
9. アクセス
10. フッター

## 2. HTML設計

### index.html
トップページ全体を記述する。

主な要素は以下。

- header
- nav
- main
- section
- footer

各セクションには識別しやすいclass名またはidを付ける。

例：

- hero
- hours
- news
- greeting
- services
- about
- staff
- access
- footer

## 3. CSS設計

### CSS/style.css
サイト全体の見た目を管理する。

主な設定内容：

- レイアウト
- 文字サイズ
- 文字色
- 背景色
- ボタン
- 表
- 画像サイズ
- 余白
- レスポンシブ対応

### カラー方針

- ベースカラー：白
- テーマカラー：薄いグリーン
- 文字色：濃いグレー
- 補助線：薄いグレーまたは薄いグリーン

## 4. JavaScript設計

### JS/script.js
スマートフォン表示時のナビゲーション開閉など、
必要な動作を記述する。

主な用途：

- スマートフォン用メニューの開閉
- 必要に応じたクリック処理

## 5. 画像管理

画像はすべて `img/` フォルダに格納する。

例：

- logo.png
- hero.jpg
- director.jpg
- hospital.jpg
- map.jpg
- 診療内容用画像
- スタッフ画像
